

# ビタミンC — 栄養教育ノート 2026-05-07

## 今日の栄養素：ビタミンC（アスコルビン酸）

### 働きと効果

ビタミンCは、体内で合成できない必須の水溶性ビタミンです。今日は**日が7日（1〜10の範囲）**のため、基本的な仕組みと科学的根拠にフォーカスして解説します。

ビタミンCの最も重要な役割は**強力な抗酸化作用**です。体内で発生する活性酸素（スーパーオキシド、ヒドロキシラジカルなど）を自らが酸化されることで無害化し、細胞膜やDNAの酸化損傷を防ぎます。また、**コラーゲン合成の必須補因子**として、プロリンとリジンの水酸化反応を触媒するプロリル-4-ヒドロキシラーゼおよびリジルヒドロキシラーゼの活性維持に不可欠です。欠乏すると正常なコラーゲンが合成できず、歯茎からの出血・皮下出血・創傷治癒遅延を特徴とする**壊血病**を引き起こします。さらに、非ヘム鉄（Fe³⁺）を還元型（Fe²⁺）に変換し**腸管での鉄吸収を促進**する作用、好中球やリンパ球の機能を支える**免疫強化作用**も科学的に確認されています。過剰摂取では通常は尿中に排泄されますが、1日3g以上の大量摂取で下痢・腹痛、腎臓結石のリスクが報告されています。

### 調理・保存による栄養素の変化

ビタミンCは**水溶性かつ熱・酸素・光に不安定**な栄養素であり、調理過程での損失が最も大きいビタミンの一つです。

- **茹で調理**：最も損失が大きく、野菜を茹でると**40〜60%が流出**します。茹で汁にビタミンCが溶け出すため、スープごと摂取すれば損失を抑えられます
- **炒め調理**：短時間の高温加熱は損失が比較的少なく、**15〜25%程度**の損失に留まります。油でコーティングされることで酸素との接触が減る効果もあります
- **蒸し調理**：水に触れないため損失は**10〜20%程度**と最小。ブロッコリーなどは蒸し調理が最も推奨されます
- **電子レンジ加熱**：短時間・少量の水分で加熱できるため、茹でるよりも**2〜3倍多く**ビタミンCを保持できます
- **水洗い・カット**：切断面からビタミンCが酸化・流出するため、**切ってから洗うのではなく、洗ってから切る**のが鉄則です
- **保存**：収穫後・カット後は時間経過とともに酸化が進行。ほうれん草は常温保存で1日約10%、冷蔵でも2日で約20%減少します。**冷凍保存**では酸化が抑制され、数ヶ月間80%以上を保持できます

### 吸収効率を上げる食べ合わせ

1. **ビタミンC ＋ 非ヘム鉄（ほうれん草・小松菜など）**
   ビタミンCは非ヘム鉄（Fe³⁺）を還元して吸収されやすいFe²⁺に変換します。ビタミンCを同時に50mg摂取するだけで、非ヘム鉄の吸収率が**3〜6倍**に向上することが複数の研究で示されています。レモン汁をほうれん草のおひたしにかけるだけで効果的です。

2. **ビタミンC ＋ ビタミンE（ナッツ・アボカドなど）**
   ビタミンEは細胞膜で抗酸化作用を発揮した後、自身が酸化型になりますが、ビタミンCがこれを**還元して再生**させます。この「抗酸化ネットワーク」により、両者を一緒に摂ることで抗酸化力が相乗的に高まります。

3. **ビタミンC ＋ コラーゲン（鶏手羽・豚足など）**
   食事から摂取したコラーゲンは一度アミノ酸に分解され体内で再合成されますが、この再合成過程でビタミンCが**必須の補因子**として働きます。コラーゲン豊富な食材とビタミンCを同時に摂ることで、皮膚や関節のコラーゲン合成が促進されます。

### 吸収を妨げる食べ合わせ（注意）

1. **ビタミンC ＋ 銅イオン（レバー・ココアなど）**
   銅イオン（Cu²⁺）はビタミンCの酸化分解を**触媒的に促進**します。サプリメントで銅とビタミンCを同時に大量摂取すると、ビタミンCの有効量が減少する可能性があります。通常の食事レベルでは問題になりにくいですが、サプリメント併用時は時間をずらすことが望ましいです。

2. **ビタミンC ＋ アルカリ性環境（重曹調理など）**
   ビタミンCは酸性環境で安定ですが、**アルカリ性（pH 7以上）では急速に分解**されます。色味を良くするために重曹（炭酸水素ナトリウム）を加えて野菜を茹でると、ビタミンCがほぼ破壊されます。

3. **喫煙・過度なアルコール**
   喫煙は体内の酸化ストレスを急激に高め、ビタミンCの消費量を増大させます。喫煙者は非喫煙者と比べて血中ビタミンC濃度が**約30〜40%低い**ことが報告されています。

## 今日のレシピ：アジの塩焼き

### 栄養情報（1人前）

| 栄養素 | 量 |
|--------|---|
| カロリー | 180 kcal |
| タンパク質 | 22 g |
| 脂質 | 8 g |
| 炭水化物 | 0 g |
| 食物繊維 | 0 g |
| 鉄分 | 0.7 mg |
| カルシウム | 65 mg |
| ビタミンC | 0 mg |
| ビタミンD | 8 μg |
| ビタミンB1 | 0.12 mg |
| オメガ3 | 1.2 g |

### 材料（1人前）

- アジ 1尾
- 塩 小さじ1/2
- レモン 適量
- 大根おろし 適量

### 作り方

1. アジに塩をふり15分置く
2. グリルで両面焼く（各5分）
3. 大根おろしとレモンを添える

### このレシピの栄養学的ポイント

アジの塩焼き自体にはビタミンCが含まれていません（0mg）が、添えるレモンと大根おろしがビタミンC供給源として重要な役割を果たします。レモン果汁大さじ1（約15ml）で約7.5mg、大根おろし50gで約12mgのビタミンCが摂取でき、さらにこのビタミンCがアジに含まれる**非ヘム鉄（0.7mg）の吸収率を高める**相乗効果があります。ビタミンDとEPA/DHAが豊富な点も見逃せません。

### 栄養保持・吸収効率UPのためのアレンジ提案

1. **レモンたっぷり＋パセリ添え**：レモンを1/4個分（約25ml）搾り、刻みパセリ（大さじ2）を振りかけます。パセリは100gあたりビタミンC 120mgと非常に豊富で、少量でもビタミンC摂取量を底上げできます。アジの鉄分吸収も促進され、今日のテーマであるビタミンCの「鉄吸収促進作用」を最大限に活かせます。

2. **赤ピーマンのマリネを副菜に**：赤ピーマン1個（約100g）を薄切りにし、オリーブオイル・酢・塩で和えた生マリネを添えます。加熱しないためビタミンCの損失がほぼゼロで、170mgものビタミンCを摂取できます。さらにオリーブオイルの脂質がアジのビタミンD（脂溶性）の吸収を補助します。

3. **すだち＋大根おろし増量で「おろしポン酢」スタイル**：大根おろしを100g（ビタミンC約24mg）に増量し、すだち果汁（ビタミンC約40mg/100ml）を加えたおろしポン酢で食べます。大根おろしに含まれるイソチオシアネートには消化促進作用もあり、タンパク質22gの消化吸収を助けます。ビタミンCは食べる直前におろす・搾ることで酸化損失を最小限に抑えられます。

## 今日のまとめ

- **ビタミンCは「調理法」で摂取量が大きく変わる** — 茹でると最大60%損失するが、蒸し・レンジ調理なら80%以上保持できる。「洗ってから切る」を習慣にしよう
- **魚料理にレモンを添えるのは栄養学的に理にかなっている** — ビタミンCが非ヘム鉄の吸収を3〜6倍に高め、抗酸化作用で脂質の酸化も抑制する
- **ビタミンCは「こまめに摂る」のが効果的** — 水溶性で体内に蓄積されないため、1日3食＋間食で分散して摂取することで血中濃度を安定的に維持できる
