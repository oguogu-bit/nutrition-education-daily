

# カルシウム — 栄養教育ノート 2026-05-05

## 今日の栄養素：カルシウム（Ca）

### 働きと効果

カルシウムは体内に最も多く存在するミネラルで、体重の約1.5〜2%を占め、その99%が骨と歯に貯蔵されています。残り1%は血液や細胞内に存在し、**神経伝達・筋肉収縮・血液凝固・ホルモン分泌**など生命維持に不可欠な役割を担います。血中カルシウム濃度は副甲状腺ホルモン（PTH）とカルシトニン、活性型ビタミンDによって厳密に調節されており、食事からの摂取が不足すると骨からカルシウムが溶出して血中濃度を維持します。この状態が慢性的に続くと**骨密度の低下・骨粗鬆症**を招きます。欠乏時にはテタニー（筋けいれん）、しびれ、不整脈のリスクも上昇します。一方、過剰摂取（主にサプリメントによる）は**高カルシウム血症・腎結石・血管石灰化**のリスクとなるため、耐容上限量を守ることが重要です。

### 調理・保存による栄養素の変化

カルシウムはミネラルであるため、**熱による分解はほとんど起こりません**。これがビタミン類との大きな違いです。ただし以下の点に注意が必要です。

- **煮汁への溶出**：野菜を茹でると水溶性ミネラルとして煮汁に一部流出します（損失率10〜20%）。スープや煮物にして汁ごと食べれば損失を防げます。
- **酢を加えた調理**：骨付き肉や小魚を酢で煮ると、骨のカルシウムが酢酸によって溶出し、摂取量が**最大1.8倍**に増加するとの報告があります。
- **切り方の影響**：切り方自体によるカルシウム損失はほぼありませんが、細かく切るほど煮汁との接触面積が増え、溶出量がわずかに増えます。
- **保存方法**：冷凍保存によるカルシウム含量の変化はほとんどありません。豆腐は冷凍すると水分が抜けて食感が変わりますが、カルシウム量は保持されます。

### 吸収効率を上げる食べ合わせ

カルシウムの腸管での吸収率は食品によって大きく異なります（牛乳：約40%、小魚：約33%、野菜：約19%）。以下の組み合わせで吸収効率を向上させることができます。

1. **カルシウム ＋ ビタミンD**：ビタミンDは小腸でのカルシウム結合タンパク質（カルビンディン）の合成を促進し、吸収率を**2〜3倍**に高めます。豆腐＋鮭、牛乳＋きくらげなどが好例です。
2. **カルシウム ＋ カゼインホスホペプチド（CPP）**：牛乳・乳製品に含まれるCPPは、腸内でカルシウムが不溶性塩を形成するのを防ぎ、吸収を促進します。牛乳のカルシウム吸収率が高い理由の一つです。
3. **カルシウム ＋ クエン酸（酢・柑橘類）**：クエン酸はカルシウムをキレートして可溶化し、吸収を促進します。小魚の南蛮漬け、酢の物などが効果的です。

### 吸収を妨げる食べ合わせ（注意）

1. **シュウ酸（ほうれん草・たけのこ）＋ カルシウム**：シュウ酸はカルシウムと不溶性のシュウ酸カルシウムを形成し、吸収を著しく阻害します。ほうれん草は下茹でしてシュウ酸を除去してから使用しましょう。
2. **フィチン酸（全粒穀物・豆類の外皮）＋ カルシウム**：フィチン酸もカルシウムと難溶性の複合体を形成します。発酵（パン酵母など）や浸水処理でフィチン酸を分解できます。
3. **過剰なリン（加工食品・清涼飲料水）＋ カルシウム**：リンの過剰摂取はカルシウムの腸管吸収を阻害し、骨からのカルシウム溶出を促進します。カルシウム：リンの比率は**1:1〜1:2**が理想です。
4. **過剰なカフェイン・ナトリウム**：いずれも腎臓からのカルシウム排泄を増加させます。塩分の多い食事はカルシウム損失を加速させる点に注意が必要です。

## 今日のレシピ：豆腐と豚バラの旨煮

### 栄養情報（1人前）

| 栄養素 | 量 |
|--------|---|
| カロリー | 350 kcal |
| タンパク質 | 22 g |
| 脂質 | 22 g |
| 炭水化物 | 8 g |
| 食物繊維 | 0.8 g |
| 鉄分 | 1.8 mg |
| カルシウム | 120 mg |
| ビタミンC | 0 mg |
| ビタミンD | 0.1 μg |
| ビタミンB1 | 0.3 mg |
| オメガ3 | 0.12 g |
| ナトリウム | 700 mg（食塩相当量 約1.8 g） |

### 材料（1人前）

- 絹ごし豆腐 1/2丁（150g）
- 豚バラ 80g
- 醤油 大さじ1
- みりん 大さじ1
- 出汁 100ml
- 生姜 少々
- 片栗粉 少々

### 作り方

1. 豚バラを炒め、豆腐を加える
2. 調味料を加えて煮込む
3. 片栗粉でとろみをつける
4. 生姜を添えて完成

### このレシピの栄養学的ポイント

本レシピは植物性タンパク質（豆腐：大豆タンパク）と動物性タンパク質（豚バラ）を組み合わせることで、必須アミノ酸をバランスよく摂取できる設計です。さらに、豆腐は**硫酸カルシウム（すまし粉）**を凝固剤として使用しているため、1人前で**120 mgのカルシウム**を供給します。これは1日推奨量（650〜800 mg）の約15〜18%に相当し、煮汁ごと食べる煮物形式のため溶出したカルシウムも無駄なく摂取できます。

### 栄養保持・吸収効率UPのためのアレンジ提案

1. **干しエビトッピング追加**：仕上げに干しエビ大さじ1（約5g）を散らすことで、カルシウムを約**355 mg上乗せ**でき、1食で推奨量の約70%をカバーできます。エビの旨味成分（グリシン・アラニン）が風味の向上にもつながります。

2. **小松菜の追加で吸収効率アップ**：小松菜50gを加えることでカルシウムを約85 mg追加でき、かつ小松菜に含まれる**ビタミンK（210μg/100g）**が骨へのカルシウム沈着を促進するオステオカルシンの活性化に寄与します。シュウ酸が少ないため、カルシウム吸収を妨げません。

3. **きくらげの追加でビタミンD強化**：乾燥きくらげ2g（水戻し後約15g）を加えると、ビタミンDを約**1.7μg追加**でき、現状ほぼ0に近いビタミンDを補強できます。ビタミンDがカルシウムの腸管吸収を促進するため、豆腐由来のカルシウム120 mgの吸収効率が大幅に向上します。

## 今日のまとめ

- **カルシウムは日本人に最も不足しがちなミネラル**。毎食意識的に摂る習慣が大切で、豆腐・小魚・乳製品を日常的に取り入れましょう
- **ビタミンDとの同時摂取がカギ**。カルシウムをいくら摂っても、ビタミンDが不足していると吸収率は大きく低下します。きのこ類・魚・日光浴を組み合わせましょう
- **煮物は汁ごと食べる**のが鉄則。カルシウムは煮汁に溶出するため、とろみをつけて煮汁も一緒に摂るこのレシピのスタイルは理にかなっています

## 明日への一言

> カルシウムの吸収を助ける鉄分もまた、日本人に不足しやすい栄養素の一つ。次回「鉄分」のテーマでは、ヘム鉄と非ヘム鉄の違いや、吸収率を劇的に変える食べ合わせの科学に迫ります。
