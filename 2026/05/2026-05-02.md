

# 脂質（総論） — 栄養教育ノート 2026-05-02

## 今日の栄養素：脂質

### 働きと効果

脂質は1gあたり9kcalと三大栄養素の中で最も高いエネルギーを供給する栄養素です。体内では**細胞膜の構成成分**、**ホルモンの原料**、**体温の保持**、**臓器の保護**など多彩な役割を担っています。さらに、脂溶性ビタミン（A・D・E・K）の吸収には脂質が不可欠であり、極端な脂質制限は栄養欠乏を招きます。脂質は大きく**飽和脂肪酸**（主に動物性）と**不飽和脂肪酸**（主に植物性・魚由来）に分類され、不飽和脂肪酸はさらに一価不飽和脂肪酸（オレイン酸など）と多価不飽和脂肪酸（オメガ3・オメガ6）に分かれます。飽和脂肪酸の過剰摂取はLDLコレステロールを上昇させ動脈硬化のリスクを高める一方、不飽和脂肪酸（特にEPA・DHA）は抗炎症作用や血中中性脂肪の低下に寄与します。欠乏すると皮膚の乾燥、免疫低下、ホルモン異常が起こり、過剰摂取は肥満・脂質異常症・心血管疾患の原因となります。

### 調理・保存による栄養素の変化

脂質そのものは比較的安定していますが、**脂肪酸の種類によって加熱耐性が大きく異なります**。

- **飽和脂肪酸（バター・ラード）**：酸化しにくく高温調理に向く。ただし過剰摂取に注意。
- **一価不飽和脂肪酸（オリーブオイル）**：180℃程度までの加熱に比較的安定。炒め物に適する。
- **多価不飽和脂肪酸（魚油・亜麻仁油・えごま油）**：**酸化しやすく加熱に弱い**。亜麻仁油やえごま油はドレッシングなど非加熱で使用するのが鉄則。魚のEPA/DHAは「焼く」と約15〜20%、「揚げる」と約50%が溶出・酸化により損失する。
- **ホイル焼き・蒸し調理**：脂質の酸化を最小限に抑えられるベストな調理法。煮汁ごといただく「汁物」も脂質の損失が少ない。
- **保存**：油脂は光・熱・空気で酸化が進む。遮光瓶での冷暗所保存が基本。開封後のえごま油は冷蔵庫で1ヶ月以内に使い切る。

### 吸収効率を上げる食べ合わせ

1. **脂質 ＋ 脂溶性ビタミン（A・D・E・K）**
   脂溶性ビタミンは脂質とともに小腸でミセルを形成して吸収されます。例えば、にんじん（βカロテン＝プロビタミンA）を油で炒めるだけで吸収率は**生食の約6〜8倍**に跳ね上がります。ほうれん草のビタミンKも同様です。

2. **魚の脂質（EPA/DHA） ＋ ビタミンE**
   n-3系脂肪酸は酸化されやすいため、**抗酸化作用のあるビタミンE**と一緒に摂ることで体内での過酸化脂質の生成を抑えられます。アーモンドやアボカドを副菜にするのが理想的です。

3. **適度な脂質 ＋ タンパク質**
   脂質は胃排出を遅らせ、タンパク質の消化吸収時間を延長します。これにより**アミノ酸の持続的な血中供給**が促され、筋タンパク合成の効率が向上します。

### 吸収を妨げる食べ合わせ（注意）

1. **過剰な食物繊維 ＋ 脂質**：大量の不溶性食物繊維は脂質のミセル形成を物理的に阻害し、脂溶性ビタミンの吸収率を低下させる可能性があります。食物繊維は重要ですが、脂溶性ビタミンを豊富に含む食事と同時に極端な量（サプリ等）を摂るのは避けましょう。

2. **植物ステロール ＋ コレステロール**：植物ステロール（大豆製品などに含有）は小腸でコレステロールの吸収を競合的に阻害します。LDLコレステロールを下げたい場合にはメリットですが、脂溶性ビタミンの吸収にも若干影響を及ぼす場合があります。

3. **トランス脂肪酸を含む加工食品**：マーガリンやショートニングに含まれるトランス脂肪酸は、体内で有益な不飽和脂肪酸の代謝を阻害し、LDLを上昇・HDLを低下させます。良質な脂質の恩恵を打ち消してしまうため、できるだけ避けましょう。

## 今日のレシピ：鮭のホイル焼き

### 栄養情報（1人前）

| 栄養素 | 量 |
|--------|---|
| カロリー | 260 kcal |
| タンパク質 | 28 g |
| 脂質 | 14 g |
| 炭水化物 | 3 g |
| 食物繊維 | 1 g |
| 鉄分 | 0.6 mg |
| カルシウム | 25 mg |
| ビタミンC | 8 mg |
| ビタミンD | 25 μg |
| ビタミンB1 | 0.2 mg |
| オメガ3 | 2.1 g |

### 材料（1人前）

- 鮭切り身 1切れ(120g)
- エリンギ 1本
- アスパラガス 2本
- バター 5g
- 塩こしょう 少々
- レモン 1/4個

### 作り方

1. アルミホイルに材料を並べバターをのせる
2. 塩こしょうをして包む
3. トースターまたはフライパンで15分蒸し焼き
4. レモンを絞って完成

### このレシピの栄養学的ポイント

本レシピは今日のテーマ「脂質」を理想的に体現しています。鮭にはEPA/DHAなどの**n-3系多価不飽和脂肪酸が2.1g**含まれ、成人の1日目安量をこの1品でほぼ充足できます。さらに**ビタミンDが25μg**と極めて豊富で、脂溶性ビタミンであるビタミンDは鮭自身の脂質やバターの脂質と一緒に摂ることでミセル形成が促進され、吸収効率が大幅に向上します。ホイル焼きは密閉空間で蒸し焼きにするため、魚の脂質が酸化しにくく、EPA/DHAの損失を最小限に抑えられる**最も脂質保持に優れた調理法**です。

### 栄養保持・吸収効率UPのためのアレンジ提案

1. **アボカドスライス添え**：ホイルを開けた後にアボカドスライスを添えることで、一価不飽和脂肪酸（オレイン酸）とビタミンEをプラス。ビタミンEがEPA/DHAの酸化を防ぎ、体内での抗酸化効果を高めます。さらにアボカドの脂質がビタミンDの吸収をさらに後押しします。

2. **パプリカ追加でビタミンC強化**：レモンだけでなく赤パプリカ（1/4個）をホイルに加えると、ビタミンCが約50mg追加されます。ビタミンCはコラーゲン合成を促進するほか、鮭の鉄分（非ヘム鉄）の吸収率を高めます。パプリカは加熱してもビタミンCが壊れにくい優秀な食材です。

3. **ホイルの汁ごとご飯にかける**：蒸し焼きで出た汁にはEPA/DHAやビタミンDが溶け出しています。この汁を捨てずにご飯にかけたり、パンに浸したりすることで、**溶出した脂溶性栄養素を余すことなく摂取**できます。糖質と脂質を一緒に摂ることで腹持ちも良くなります。

## 今日のまとめ

- 🐟 **脂質の質が大切**：量を減らすことだけに注目せず、飽和脂肪酸を減らし、n-3系不飽和脂肪酸（EPA/DHA）を増やす「脂質の質の転換」を意識しましょう
- 🔥 **調理法で脂質の価値が変わる**：ホイル焼き・蒸し調理はEPA/DHAの酸化損失が最小。揚げ物は約50%の損失。同じ鮭でも調理法で栄養価が大きく変わります
- 🥑 **脂溶性ビタミンは脂質と一緒に**：ビタミンA・D・E・Kを含む食材は、必ず適度な脂質と組み合わせて摂ることで吸収率が飛躍的に向上します
