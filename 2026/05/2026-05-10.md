

# オメガ3脂肪酸 — 栄養教育ノート 2026-05-10

## 今日の栄養素：オメガ3脂肪酸（DHA・EPA・α-リノレン酸）

### 働きと効果

オメガ3脂肪酸は、体内で合成できない**必須脂肪酸**の一種で、大きく3つに分類されます。植物由来の**α-リノレン酸（ALA）**、そして魚由来の**EPA（エイコサペンタエン酸）**と**DHA（ドコサヘキサエン酸）**です。

EPAは血液中の中性脂肪を低下させ、血小板凝集を抑制することで**動脈硬化・血栓の予防**に寄与します。DHAは脳の神経細胞膜や網膜のリン脂質に高濃度で存在し、**認知機能・視機能の維持**に不可欠です。また、両者ともに炎症性サイトカインの産生を抑え、**慢性炎症の制御**に重要な役割を果たします。

欠乏すると、皮膚の乾燥・湿疹、集中力低下、抑うつ傾向、心血管リスクの上昇が報告されています。一方、過剰摂取（サプリメント等で3g/日以上）では出血傾向の増加やLDLコレステロール上昇の可能性があり、**食事からの適量摂取が基本**です。α-リノレン酸から体内でEPA・DHAへの変換率はわずか**5〜15%**と低いため、魚からの直接摂取が効率的です。

### 調理・保存による栄養素の変化

オメガ3脂肪酸は**多価不飽和脂肪酸**であるため、**酸化・熱・光**に非常に弱い性質を持ちます。

| 条件 | 影響と対策 |
|------|----------|
| **高温加熱（揚げ物）** | EPAは揚げ調理で**約50〜60%が減少**。高温の油中で酸化・分解が進む |
| **焼き魚** | グリル焼きでは**20〜30%**が脂とともに流出。受け皿の脂は活用困難 |
| **煮魚** | 煮汁にEPA・DHAが溶出するが、**煮汁ごと食べれば損失は10%以下**に抑えられる |
| **刺身・生食** | 損失ほぼゼロ。最も効率的なオメガ3摂取法 |
| **えごま油・亜麻仁油** | 加熱厳禁。開封後は**冷蔵保存で1〜2ヶ月以内**に使い切る |
| **缶詰** | 製造時に加熱されるが、液汁中にEPA・DHAが移行。**液汁ごと使えば高効率** |

> 🔑 **ポイント**: 魚は「**生 > 煮る（汁ごと）> 焼く > 揚げる**」の順でオメガ3の保持率が高い。

### 吸収効率を上げる食べ合わせ

1. **オメガ3 ＋ ビタミンE（抗酸化）**
   EPA・DHAは体内でも酸化されやすく、ビタミンEが**脂質の過酸化を防ぐ**ガードマン役になります。さばの味噌煮＋アーモンド入りサラダ、刺身＋アボカドなどが好例。ビタミンEの摂取がオメガ3の体内利用効率を高めることが複数の研究で示されています。

2. **オメガ3 ＋ 脂質を含む食事（脂溶性の性質）**
   オメガ3は脂溶性のため、完全な空腹時より**適度な脂質を含む食事と一緒に**摂ると吸収率が向上します（胆汁酸の分泌が促進されるため）。えごま油はサラダのドレッシングとして油脂を含む食事に組み込むのが理想的です。

3. **EPA・DHA ＋ クルクミン（ターメリック）**
   近年の研究では、クルクミンがDHAの脳内取り込みを促進する可能性が示唆されています。魚のカレー風味ソテーなど、スパイスとの組み合わせにも科学的意義があります。

### 吸収を妨げる食べ合わせ（注意）

1. **オメガ3 ＋ 過剰なオメガ6脂肪酸**
   オメガ6（サラダ油・大豆油・コーン油に多い）とオメガ3は、体内で**同じ代謝酵素（Δ6デサチュラーゼ）**を奪い合います。オメガ6の過剰摂取は、EPA・DHAへの変換と利用を阻害し、炎症性のアラキドン酸カスケードを亢進させます。理想的な比率は**オメガ6：オメガ3 ＝ 4:1以下**ですが、現代の日本人の食事では10:1以上に偏りがちです。

2. **酸化した油脂との同時摂取**
   何度も使いまわした揚げ油（過酸化脂質）とオメガ3を同時摂取すると、体内の酸化ストレスが増大し、オメガ3のメリットが相殺されるリスクがあります。

3. **アルコールの過剰摂取**
   慢性的なアルコール摂取は脂質代謝酵素の機能を低下させ、オメガ3の代謝・利用効率を下げることが報告されています。

## 今日のレシピ：ほうれん草のごま和え

### 栄養情報（1人前）

| 栄養素 | 量 |
|--------|---|
| カロリー | 80 kcal |
| タンパク質 | 4 g |
| 脂質 | 5 g |
| 炭水化物 | 5 g |
| 食物繊維 | 2.8 g |
| 鉄分 | 2 mg |
| カルシウム | 85 mg |
| ビタミンC | 35 mg |
| ビタミンD | 0 μg |
| ビタミンB1 | 0.07 mg |
| オメガ3 | 0.05 g |

### 材料（1人前）

- ほうれん草 100g
- 白ごま 大さじ1
- 醤油 小さじ1
- みりん 小さじ1
- 砂糖 小さじ0.5

### 作り方

1. ほうれん草を塩茹でし冷水で冷やす
2. 3cm幅に切り水気を絞る
3. 調味料・すりごまと和える

### このレシピの栄養学的ポイント

本レシピのオメガ3含有量は0.05gと少量ですが、**鉄分（2mg）＋ビタミンC（35mg）**の組み合わせが最大の強みです。ほうれん草の非ヘム鉄は単独では吸収率5%程度ですが、ビタミンCが鉄を還元型（Fe²⁺）に変換することで吸収率が**3〜6倍に向上**します。さらに白ごまはカルシウム（85mg）を含み、骨の健康にも寄与します。**今日のテーマであるオメガ3を補うには、主菜にEPA・DHAが豊富な魚料理を組み合わせるのが最適**です。

### 栄養保持・吸収効率UPのためのアレンジ提案

1. **くるみプラス・ごま和え**: 白ごまに加えて**砕いたくるみ（10g）**を混ぜ込む。くるみはα-リノレン酸を100gあたり約9g含み、この追加だけでオメガ3を約0.9g上乗せできます。香ばしさも加わり風味も向上。今日のテーマ「オメガ3」の摂取量を副菜レベルで大幅に改善する最も手軽なアレンジです。

2. **えごま油仕上げ**: 和えた後の仕上げに**えごま油を小さじ1/2（約2.3g）**を回しかける。α-リノレン酸を約1.3g追加でき、1日の目安量の約65%を副菜だけでカバーできます。加熱せず仕上げに使うことで、熱に弱いオメガ3の酸化を防ぎます。

3. **しらす＋ごま和え**: 仕上げに**しらす干し（10g）**をトッピング。EPA・DHAを直接追加できるほか、ビタミンD（約6μg/100g）が加わることで、ほうれん草・ごまのカルシウム吸収を促進します。オメガ3＋ビタミンD＋カルシウムの三位一体で栄養価が飛躍的に向上します。
