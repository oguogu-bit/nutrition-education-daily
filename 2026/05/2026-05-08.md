

# ビタミンD — 栄養教育ノート 2026-05-08

## 今日の栄養素：ビタミンD

### 働きと効果

ビタミンDは脂溶性ビタミンの一つで、体内で「ホルモン」に近い働きをする特異な栄養素です。最も重要な役割は**小腸でのカルシウム・リンの吸収促進**であり、骨の形成・維持に不可欠です。ビタミンDが不足するとカルシウムの吸収率は著しく低下し、成人では**骨軟化症**、小児では**くる病**を引き起こします。近年の研究では、免疫細胞（T細胞・マクロファージ）上のビタミンD受容体（VDR）を介した**免疫調節作用**が注目されており、感染症リスクの低減や自己免疫疾患との関連も報告されています。また、筋力維持にも関与し、高齢者の転倒・骨折リスク低減にも寄与します。脂溶性のため体内に蓄積されやすく、サプリメントによる**過剰摂取では高カルシウム血症・腎障害**のリスクがあるため、耐容上限量を超えないよう注意が必要です。

### 調理・保存による栄養素の変化

ビタミンDは脂溶性ビタミンの中でも**比較的熱に安定**しており、通常の加熱調理（焼く・煮る・蒸す）での損失率は概ね**10〜20%程度**と小さいのが特徴です。

- **焼き調理**：鮭の塩焼きなどでは損失は約10%。脂とともに流出する分がわずかにある程度です。
- **煮込み調理**：煮汁に溶出するため、**煮汁ごと食べるスープや鍋料理**が理想的。煮汁を捨てると20〜30%損失する可能性があります。
- **揚げ調理**：高温短時間であれば損失は少ないが、長時間の加熱は避けたい。
- **干物・天日干し**：しらす干しや干ししいたけは、紫外線によりビタミンD前駆体が**ビタミンDに変換される**ため、天日干しにより含有量がむしろ増加します。干ししいたけは食べる前に**30分〜1時間日光に当てる**だけでもビタミンD量が数倍に増えることが報告されています。
- **保存**：冷暗所保存で安定。光（紫外線）に当たると分解が進む食品もあるため、サプリメント等は遮光保存が基本です。

### 吸収効率を上げる食べ合わせ

1. **ビタミンD ＋ 脂質（油脂）**
   ビタミンDは脂溶性のため、脂質と一緒に摂ることで**吸収率が最大で2〜3倍向上**します。きのこのバターソテー、鮭のオリーブオイル焼きなど、油脂を活用した調理が効果的です。ノンオイルドレッシングのサラダだけでは吸収効率が低下します。

2. **ビタミンD ＋ カルシウム ＋ ビタミンK₂**
   ビタミンDがカルシウムの腸管吸収を促進し、ビタミンK₂が骨へのカルシウム沈着を助ける「**骨のゴールデントライアングル**」。しらす＋納豆＋チーズの組み合わせはこの3つを同時に摂取できる理想的な食べ合わせです。

3. **ビタミンD ＋ マグネシウム**
   マグネシウムはビタミンDを活性型（1,25-ジヒドロキシビタミンD）に変換する酵素の補因子です。マグネシウムが不足しているとビタミンDを十分に摂っても**活性化されにくい**ため、海藻類・ナッツ類との組み合わせが重要です。

### 吸収を妨げる食べ合わせ（注意）

- **過剰な食物繊維との同時摂取**：大量の食物繊維（特に不溶性）は脂溶性ビタミンを吸着し、そのまま排泄してしまう可能性があります。極端な繊維サプリメントとビタミンD食品の同時摂取は避けましょう。
- **ミネラルオイル（流動パラフィン）**：便秘薬に使われることがあるミネラルオイルは、脂溶性ビタミンを溶かし込んで体外に排出するため、ビタミンDの吸収を著しく阻害します。
- **脂質制限ダイエットの過度な実践**：脂質をほとんど摂らない極端な食事は、ビタミンDの吸収効率を大幅に低下させます。適度な脂質（1食あたり10g程度）は確保しましょう。

## 今日のレシピ：豚ヒレカツ（オーブン焼き）

### 栄養情報（1人前）

| 栄養素 | 量 |
|--------|---|
| カロリー | 340 kcal |
| タンパク質 | 28 g |
| 脂質 | 14 g |
| 炭水化物 | 20 g |
| 食物繊維 | 0.5 g |
| 鉄分 | 0.9 mg |
| カルシウム | 20 mg |
| ビタミンC | 0 mg |
| ビタミンD | 0.1 μg |
| ビタミンB1 | 0.78 mg |
| オメガ3 | 0.1 g |

### 材料（1人前）

- 豚ヒレ肉 150g
- パン粉 大さじ3
- 卵 1/2個
- 薄力粉 大さじ1
- 塩こしょう 少々
- オリーブ油 大さじ1

### 作り方

1. 豚ヒレを叩いて薄くし塩こしょう
2. 薄力粉→卵→パン粉の順にまぶす
3. オリーブ油をかけ200℃のオーブンで20分

### このレシピの栄養学的ポイント

このレシピは揚げずにオーブンで焼くことでカロリーを抑えつつ、豚ヒレ肉の優れたビタミンB1（0.78mg）を活かした一品です。ただし、今日のテーマであるビタミンDは0.1μgとごくわずか。豚肉は本来ビタミンD含有量が低い食材のため、**副菜や付け合わせでビタミンDを補完する戦略**が重要です。オリーブ油（大さじ1＝約14gの脂質）が含まれるため、副菜から摂るビタミンDの吸収を助ける脂質は確保できています。

### 栄養保持・吸収効率UPのためのアレンジ提案

1. **しらす入りおろしソース**：大根おろしにしらす干し（大さじ2＝約10g）を混ぜてカツにかける。しらすのビタミンD（約6μg追加）を脂質豊富なカツと一緒に摂ることで吸収効率が大幅にアップします。さっぱりとした味わいも楽しめます。

2. **まいたけの付け合わせ追加**：まいたけ50gをオーブンの空きスペースで一緒に焼く。まいたけのビタミンD（約2.5μg追加）に加え、βグルカンによる免疫サポート効果も得られます。カツと同じオーブンで焼けるため手間も増えません。

3. **卵黄ソース（自家製タルタル）**：卵1/2個の残り＋追加の卵黄1個分を使い、ゆで卵のタルタルソースを作る。卵黄のビタミンD（約1μg追加）とカルシウム吸収に役立つタンパク質を同時に強化。マヨネーズの脂質がビタミンDの吸収をさらに助けます。

## 今日のまとめ

- **ビタミンDは「食事＋日光」の二刀流で確保**する栄養素。5〜6月は日光合成の好条件が揃う季節なので、1日15〜30分の日光浴（手・顔程度の露出）を意識しましょう
- **脂溶性であることを活かす**：油脂と一緒に摂る、煮汁ごと食べる、干ししいたけは日光に当ててから使う——この3つを覚えておくだけで摂取効率が格段に上がります
- **主菜にビタミンDが少ない日は副菜で補完**：今日の豚ヒレカツのように主菜がビタミンD低含有の場合、しらすおろし・きのこソテー・卵料理を1品添えるだけで目安量に近づけます
