

# ビタミンA/βカロテン — 栄養教育ノート 2026-05-11

## 今日の栄養素：ビタミンA（レチノール）/ βカロテン（プロビタミンA）

### 働きと効果

ビタミンAは、視覚機能・皮膚や粘膜の維持・免疫機能の調節に不可欠な脂溶性ビタミンです。網膜で光を感知するロドプシンの構成成分であり、不足すると**暗順応の低下（夜盲症）**が起こります。また、上皮細胞のターンオーバーに関わり、不足すると皮膚の乾燥・角化、呼吸器や消化管の粘膜バリア機能が低下し感染症リスクが増大します。一方、レチノール（動物性由来の既成ビタミンA）は脂溶性のため体内（主に肝臓）に蓄積しやすく、**過剰摂取では頭痛・吐き気・肝障害・妊婦では催奇形性**のリスクがあります。βカロテンは植物性食品に含まれるプロビタミンAで、体内で必要量だけビタミンAに変換されるため、過剰症のリスクが極めて低いのが特徴です。日常的には**緑黄色野菜からβカロテンとして摂る**のが安全かつ合理的な方法といえます。

### 調理・保存による栄養素の変化

ビタミンA（レチノール）は比較的**熱に安定**しており、通常の加熱調理（炒め物・煮物・焼き物）での損失率は**10〜20%程度**と小さい脂溶性ビタミンです。

- **炒め調理**：油脂と共に加熱することでβカロテンの吸収率が**生食時の8〜10%から60〜70%に飛躍的に上昇**。最も推奨される調理法です
- **煮物**：βカロテンは水に溶けにくいため煮汁への溶出は少ないものの、煮汁ごと摂取するのが理想的
- **生食（サラダ）**：細胞壁に閉じ込められたβカロテンの吸収率はわずか8〜10%。ドレッシング（油脂）をかけることで改善可能
- **冷凍保存**：βカロテンは冷凍による損失が少なく、ブランチング（短時間加熱）後の冷凍で**90%以上保持**
- **切り方の工夫**：にんじんの場合、細胞壁を壊すほど（すりおろし＞千切り＞乱切り）βカロテンの遊離量が増え、吸収率向上に寄与

### 吸収効率を上げる食べ合わせ

1. **βカロテン ＋ 油脂**：βカロテンは脂溶性のため、少量の油脂（5g程度）と一緒に摂ると吸収率が約**6〜7倍**に向上します。にんじんのきんぴら、かぼちゃの天ぷら、ほうれん草のバターソテーなどが好例です
2. **ビタミンA ＋ ビタミンE（抗酸化の相乗効果）**：ビタミンEはビタミンAの酸化を防ぎ、体内での安定性を高めます。アーモンドやアボカドと緑黄色野菜の組み合わせが有効です
3. **βカロテン ＋ たんぱく質**：レチノール結合タンパク質（RBP）として血中輸送されるため、適切なたんぱく質摂取がビタミンAの体内利用効率を支えます。肉・魚・豆腐との組み合わせが理想的です

### 吸収を妨げる食べ合わせ（注意）

1. **極端な低脂肪食との組み合わせ**：脂質がほとんどない食事（ノンオイルドレッシングのサラダのみ等）では、βカロテンのミセル化が不十分で吸収率が著しく低下します。「ヘルシー志向で油を完全カット」は逆効果です
2. **食物繊維の過剰摂取と同時摂取**：大量の不溶性食物繊維は消化管通過速度を速め、βカロテンの吸収時間が短縮される可能性があります。サプリメント等で食物繊維を大量に摂る場合は時間をずらすのが無難です
3. **ミネラルオイル（流動パラフィン）**：一部の加工食品や便秘薬に含まれるミネラルオイルは、脂溶性ビタミン全般の吸収を阻害します。常用している場合は注意が必要です

## 今日のレシピ：切り干し大根の煮物

### 栄養情報（1人前）

| 栄養素 | 量 |
|--------|---|
| カロリー | 70 kcal |
| タンパク質 | 2 g |
| 脂質 | 1 g |
| 炭水化物 | 13 g |
| 食物繊維 | 3.5 g |
| 鉄分 | 1.1 mg |
| カルシウム | 100 mg |
| ビタミンC | 0 mg |
| ビタミンD | 0 μg |
| ビタミンB1 | 0.04 mg |
| オメガ3 | 0 g |

### 材料（1人前）

- 切り干し大根 30g
- 人参 1/3本
- 油揚げ 1/4枚
- 出汁 200ml
- 醤油 大さじ1.5
- みりん 大さじ1
- 砂糖 小さじ1

### 作り方

1. 切り干し大根を水で戻す
2. 人参・油揚げを細切りにする
3. 出汁で煮て調味料を加え15分煮る

### このレシピの栄養学的ポイント

このレシピにはカルシウム（100mg）と食物繊維（3.5g）が豊富に含まれ、常備菜として冷蔵5日間保存できる点が大きな魅力です。今日のテーマであるビタミンA/βカロテンとの関連では、**材料の「人参」がβカロテンの重要な供給源**です。人参1/3本（約50g）には約4,300μgのβカロテンが含まれ、油揚げに含まれる脂質（油脂分）と一緒に煮ることで、βカロテンのミセル化が促進され吸収率が向上します。煮物という調理法は加熱による細胞壁の軟化も加わり、生食よりも効率的にβカロテンを利用できます。

### 栄養保持・吸収効率UPのためのアレンジ提案

1. **ごま油仕上げ**：完成直前にごま油を小さじ1回しかけることで、βカロテンの吸収率がさらに向上します。油揚げだけでは脂質が1gと少ないため、良質な植物油を追加することでミセル化効率を高め、風味もアップする一石二鳥のアレンジです

2. **ほうれん草・小松菜のちょい足し**：仕上げの最後2分でほうれん草や小松菜を加えると、βカロテン量が大幅に増加するだけでなく、ビタミンC（非ヘム鉄の吸収促進）も加わり、切り干し大根由来の鉄分1.1mgの吸収率を高める相乗効果が期待できます

3. **かぼちゃ＋白ごま追加バージョン**：かぼちゃ50gを乱切りにして最初から一緒に煮ると、βカロテン量が約2,000μg増加し、ビタミンA供給源としてのレシピ価値が飛躍的に高まります。白ごまをトッピングすれば、ビタミンE（抗酸化でβカロテンを保護）とカルシウムも追加され、栄養バランスが一層向上します

## 今日のまとめ

- 🥕 **βカロテンは「油と加熱」で吸収率が劇的に変わる**。生食の8%から油脂併用で60〜70%に上昇するため、緑黄色野菜は炒め物・油を使った煮物で食べるのが最も効率的
- ⚠️ **レバーなど動物性のレチノールは過剰症に注意**。一方、βカロテン（植物性）は体内で必要な分だけ変換されるため安全性が高い。日常の摂取源は緑黄色野菜を中心に
- 🍳 **切り干し大根の煮物は少量の油脂を加えるだけでβカロテン吸収率UP**。人参＋油揚げの組み合わせは理にかなっており、ごま油の追加や緑黄色野菜のちょい足しでさらに栄養価を高められる
