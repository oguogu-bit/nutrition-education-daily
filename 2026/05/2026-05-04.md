

# 食物繊維 — 栄養教育ノート 2026-05-04

## 今日の栄養素：食物繊維（水溶性・不溶性）

### 働きと効果

食物繊維は「ヒトの消化酵素では分解されない食物成分」の総称であり、**水溶性食物繊維**と**不溶性食物繊維**の2種類に大別されます。水溶性食物繊維（ペクチン・βグルカン・イヌリンなど）は水に溶けてゲル状になり、糖質や脂質の吸収を緩やかにし、食後血糖値の急上昇を抑制します。一方、不溶性食物繊維（セルロース・ヘミセルロース・リグニンなど）は水分を吸収して膨張し、便のかさを増やして腸の蠕動運動を促進します。さらに、大腸に届いた食物繊維は腸内細菌によって発酵され、**短鎖脂肪酸（酪酸・酢酸・プロピオン酸）** を産生。これが腸管バリア機能の強化、免疫調節、大腸がんリスクの低減に寄与します。欠乏すると便秘、腸内環境の悪化、生活習慣病リスクの上昇が懸念されます。過剰摂取による深刻な健康被害は通常ありませんが、急激な大量摂取は腹部膨満感やガスの増加を引き起こすことがあります。

### 調理・保存による栄養素の変化

食物繊維は**熱に対して非常に安定**しており、加熱調理による損失はほとんどありません。これはビタミンCやB群と異なる大きな利点です。

- **茹でる**: 食物繊維自体は溶出しにくいが、水溶性食物繊維の一部は茹で汁に溶出する（約5〜15%）。→ **汁ごと食べるスープ・味噌汁が理想的**
- **炒める・焼く**: 損失はほぼゼロ。加熱により野菜のかさが減り、結果として**摂取量を増やしやすい**
- **切り方**: 細かく切っても食物繊維の総量は変わらないが、不溶性食物繊維の「便のかさ増し効果」はやや減少する。便秘解消目的なら**大きめカット**が有効
- **乾燥・保存**: 乾物（切り干し大根・干し椎茸など）は水分が抜けることで食物繊維が濃縮され、**重量あたりの含有量が飛躍的に増加**する
- **冷凍**: 構造がやや崩れるが、食物繊維量に大きな変化はない

### 吸収効率を上げる食べ合わせ

食物繊維は「吸収される栄養素」ではなく「消化されずに大腸まで届く」ことに価値があるため、ここでは**腸内環境への効果を最大化する組み合わせ**を紹介します。

1. **水溶性食物繊維 ＋ 発酵食品（プロバイオティクス）**
   - 例：押麦ごはん ＋ 納豆、ごぼうサラダ ＋ ヨーグルトドレッシング
   - 根拠：水溶性食物繊維はプレバイオティクスとして善玉菌のエサになり、発酵食品の生きた菌と組み合わせることで**シンバイオティクス効果**が得られ、短鎖脂肪酸の産生が最大化される

2. **不溶性食物繊維 ＋ 十分な水分**
   - 例：野菜たっぷりの食事 ＋ 味噌汁・スープ
   - 根拠：不溶性食物繊維は水分を吸収して膨張することで腸を刺激するため、水分不足だと逆に便が硬くなり便秘を悪化させる可能性がある

3. **食物繊維 ＋ オリゴ糖**
   - 例：ごぼう ＋ 玉ねぎ（フラクトオリゴ糖）の煮物
   - 根拠：オリゴ糖も難消化性で大腸まで届き、食物繊維と合わせてビフィズス菌の増殖を相乗的に促進する

### 吸収を妨げる食べ合わせ（注意）

食物繊維自体が**他の栄養素の吸収を阻害する側**になることがあるため注意が必要です。

1. **食物繊維（特にフィチン酸を含む穀物の外皮） ＋ 鉄・亜鉛・カルシウム**
   - 玄米・全粒粉に含まれるフィチン酸がミネラルとキレートを形成し、吸収率を低下させる。対策として**ビタミンCの同時摂取**やよく噛むことが有効

2. **食物繊維の過剰摂取 ＋ 脂溶性ビタミン（A・D・E・K）**
   - 極端に大量の食物繊維は腸管内で脂溶性ビタミンを吸着し、吸収率を下げる可能性がある。サプリメントでの過剰な食物繊維摂取時に注意

3. **不溶性食物繊維の大量摂取 ＋ 水分不足**
   - 前述の通り、水分なしでの大量摂取は便秘の悪化やミネラル吸収障害を招く

## 今日のレシピ：鶏もも照り焼き

### 栄養情報（1人前）

| 栄養素 | 量 |
|--------|---|
| カロリー | 320 kcal |
| タンパク質 | 28 g |
| 脂質 | 18 g |
| 炭水化物 | 10 g |
| 食物繊維 | 0 g |
| 鉄分 | 0.7 mg |
| カルシウム | 12 mg |
| ビタミンC | 0 mg |
| ビタミンD | 0.3 μg |
| ビタミンB1 | 0.15 mg |
| オメガ3 | 0.1 g |

### 材料（1人前）

- 鶏もも肉 150g
- 醤油 大さじ1.5
- みりん 大さじ1.5
- 砂糖 小さじ1
- 酒 大さじ1

### 作り方

1. 鶏もも肉の皮をフォークで刺す
2. フライパンに皮目を下にして焼く
3. 裏返してフタをし蒸し焼き
4. 調味料を加えて絡める

### このレシピの栄養学的ポイント

鶏もも肉はアミノ酸スコア100の良質な動物性タンパク質源で、消化吸収率も非常に優れています。しかし今日のテーマ「食物繊維」の観点から見ると、**このレシピ単体では食物繊維が0g**であることが最大の課題です。高タンパク質な主菜に食物繊維が豊富な副菜・汁物を組み合わせることで、食後血糖値の上昇抑制やタンパク質の消化を助ける腸内環境の維持が期待できます。

### 栄養保持・吸収効率UPのためのアレンジ提案

1. **ごぼう・れんこんの照り焼き合わせ**: 鶏肉と一緒にごぼう（薄切り）やれんこん（乱切り）をフライパンで焼き、同じ照り焼きダレで絡めます。ごぼうの水溶性食物繊維（イヌリン）と不溶性食物繊維の両方を摂取でき、**1食あたり約3〜4gの食物繊維をプラス**できます。根菜の歯応えにより咀嚼回数も増え、満腹感の向上にも寄与します。

2. **きのこたっぷりトッピング**: しめじ・エリンギ・舞茸などを一緒に蒸し焼きにし、照り焼きの付け合わせにします。きのこ類は100gあたり約3〜5gの食物繊維を含み、特にβグルカン（水溶性食物繊維の一種）が腸内環境改善と免疫力強化に寄与します。さらにビタミンDも補え、このレシピで不足する栄養素を補完できます。

3. **副菜に押麦入り野菜スープを添える**: 照り焼きの付け合わせとして、押麦・玉ねぎ・にんじん・わかめを入れたコンソメスープを用意します。押麦のβグルカン（水溶性食物繊維）が食後血糖値の上昇を緩やかにし、わかめのアルギン酸が余分なナトリウム（照り焼きの醤油由来）の排出を促進します。**食物繊維約5g＋減塩効果**の一石二鳥です。

## 今日のまとめ

- 🥬 **水溶性と不溶性を意識して摂る**: 水溶性は血糖値・コレステロール対策に、不溶性は便通改善に効果的。押麦・ごぼうは両方含むのでおすすめ
- 🍗 **肉料理には食物繊維豊富な副菜を必ずセットに**: 照り焼きのような主菜単体では食物繊維ゼロ。根菜・きのこ・海藻の副菜で1食6g以上を目指そう
- 💧 **食物繊維を増やすときは水分も一緒に**: 特に不溶性食物繊維は水分と合わさって初めて腸内で正しく機能する。味噌汁・スープを1杯添えるだけで効果倍増
